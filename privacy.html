privacy policy

Actify is a personal project. Here's exactly what it does with your data.

what's collected

  • Your name and profile picture from Google, used only to personalize the app.
  • The character, interests, schedule, tasks, and activity feedback you enter, so the app can make useful suggestions.
  • If you connect Google Calendar, read-only access to your calendar's busy/free times for today — Actify never creates, edits, or deletes calendar events, and never sees event titles or details, only start/end times.

where it's stored

Everything is stored in a Supabase database, protected so only your own account can read or write your own data.

what's never done

  • Your data is never sold, shared, or used for advertising.
  • There's no analytics or tracking beyond what's needed to run the app itself.
  • Calendar access is read-only and never persisted beyond the current session.

third-party services

Actify pulls public content (movies, books, games, articles, nearby places) from TMDB, Open Library, RAWG, dev.to, Hacker News, and OpenStreetMap. These requests don't include any of your personal data — only a time-budget and mood, used to filter results.

questions

This is a solo-built personal project. Reach out via the GitHub repo with any questions.
